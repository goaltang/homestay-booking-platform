# Homestay Front 前端应用

homestay-front 同时服务房客和房东，本地入口为 http://localhost:5173。技术栈见 [[项目技术栈]]，启动见 [[开发环境配置]]。

## 应用职责

| 使用者 | 工作 | 详细说明 |
|---|---|---|
| 房客 | 浏览、搜索、地图、收藏 | [[功能模块-房源搜索]]、[[功能模块-地图找房]]、[[功能模块-收藏]] |
| 房客 | 预订、支付、退款、履约 | [[功能模块-订单管理]]、[[功能模块-支付与财务]]、[[功能模块-入住退房]] |
| 房客与房东 | 聊天、通知、评价 | [[功能模块-聊天消息]]、[[功能模块-通知中心]]、[[功能模块-评价管理]] |
| 房东 | 房源、订单、库存与经营 | [[功能模块-房东中心]]、[[功能模块-房东日历]] |
| 登录用户 | AI 客服与待确认操作 | [[AI客服Agent-权限与工具边界]] |

## 代码入口

| 目录 | 作用 |
|---|---|
| src/views/ | 页面，含 host、user、order 等入口 |
| src/components/ | 业务与共享组件 |
| src/api/ | 接口封装 |
| src/composables/ | 地图与搜索等交互逻辑 |
| src/stores/ | Pinia 状态 |
| src/router/ | 路由与守卫 |

核对了目录和应用职责，具体流程以模块文档和代码为准。项目全貌见 [[Homestay 项目结构总览]]。
