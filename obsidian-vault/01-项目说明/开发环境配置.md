# 开发环境配置

本页维护本地开发入口。安装步骤、配置字段和排障统一看 [完整安装教程](../../docs/INSTALL.md)，这里不再复制一套流程。

## 服务与端口

| 服务 | 本地地址 | 用途 |
|---|---|---|
| 用户端 / 房东端 | `http://localhost:5173` | 两种角色共用 homestay-front |
| 管理端 | `http://localhost:5174` | 独立管理后台 |
| 后端 | `http://localhost:8081` | local profile 设置 server.port=8081，两端 Vite 代理使用该端口 |
| MySQL | `localhost:3306` | homestay_db，Flyway 管理表结构 |
| Redis | `localhost:6379` | 报价缓存、锁等 |
| Elasticsearch + IK | `http://localhost:9200` | 当前后端启动需要 ES 在线 |
| RabbitMQ | `localhost:5672`，管理台 `http://localhost:15672` | 三个消息场景按需启用 |

配置模板 application.example.properties 仍写 8080；复制到 application-local.properties 后按安装教程改成 8081。本机 8080 常被 Dify 使用。

## 启动入口

先按安装教程准备 MySQL、Redis、Elasticsearch 与本地配置，再从根目录打开三个终端：

```bash
cd homestay-backend
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

```bash
cd homestay-front
npm run dev
```

```bash
cd homestay-admin
npm run dev
```

## 环境约定

| 项目 | 当前约定 |
|---|---|
| 配置文件 | properties，真实配置放 Git 忽略的本地文件 |
| ES 开关 | elasticsearch.enabled=false 关闭索引同步并允许查询降级，不能解除 repository 初始化依赖 |
| AI 客服 | 示例默认 agent.llm.enabled=false，启用与 LLM 配置见安装教程 |
| 支付沙箱 | WSL 曾需 JVM HTTPS 代理，参数和密钥排障见根目录 AGENTS.md |
| 测试隔离 | SpringBootTest 必须使用 test profile 与 H2，禁止清理真实表 |
| 运行环境 | Java 17、Node 20 等要求看安装教程与 CI |

核对范围为配置示例、两个 Vite 代理与现有安装教程，没有重新启动应用或执行支付联调。
