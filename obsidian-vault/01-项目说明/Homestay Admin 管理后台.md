# Homestay Admin 管理后台

homestay-admin 是管理员独立应用，本地入口为 http://localhost:5174。技术栈见 [[项目技术栈]]，启动见 [[开发环境配置]]。

## 应用职责

| 工作 | 详细说明 |
|---|---|
| 查看平台数据 | [[功能模块-管理仪表盘]]、[[功能模块-统计分析]] |
| 审核房源与身份 | [[功能模块-审核模块]]、[[功能模块-用户管理]] |
| 管理订单与争议 | [[功能模块-订单管理]]、[[功能模块-争议处理]] |
| 营销与定价配置 | [[功能模块-营销促销]]、[[功能模块-定价引擎]] |
| 通知、公告与系统配置 | [[功能模块-通知中心]]、[[功能模块-公告通知]]、[[功能模块-系统管理]] |
| 争议辅助建议 | [[AI客服Agent-权限与工具边界]]，管理员审阅后自行裁决 |

## 代码入口

| 目录 | 作用 |
|---|---|
| src/views/ | 管理页面 |
| src/api/ | 接口封装 |
| src/components/ | 通用组件 |
| src/composables/ | 共享逻辑，CRUD 见 [[前端-useCrud-使用指南]] |
| src/stores/ | 登录与应用状态 |
| src/router/ | 后台路由 |

npm run build 包含 vue-tsc --noEmit 与 Vite 构建。目录与构建脚本已静态核对，本次未运行应用构建。
