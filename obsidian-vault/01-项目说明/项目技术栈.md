# 项目技术栈

本页覆盖三端。版本范围来自依赖声明，不将范围写成当前机器已经安装的精确版本。

| 层 | 主要技术 | 依据 |
|---|---|---|
| 房客 / 房东端 | Vue 3、TypeScript、Vite 5、Pinia 2、Element Plus、Axios、高德地图 JSAPI 2.0 | [package.json](../../homestay-front/package.json) |
| 管理端 | Vue 3、TypeScript、Vite 6、Pinia 3、Element Plus、ECharts | [package.json](../../homestay-admin/package.json) |
| 后端 | Java 17、Spring Boot 3.0.2、JPA、Spring Security、JWT | [pom.xml](../../homestay-backend/pom.xml) |
| 持久化 | MySQL、Flyway | pom.xml 与迁移目录 |
| 缓存与锁 | Redis、Redisson、Caffeine | pom.xml、CacheConfig、具体服务 |
| 搜索 | Elasticsearch、IK、JPA 降级 | 索引与搜索服务 |
| 消息与通知 | RabbitMQ、WebSocket、延迟和重试队列 | MQ 配置与实现 |
| AI 客服 | OpenAI 兼容 HTTP、JSON 编排、工具白名单、用户确认 | [[AI客服Agent-权限与工具边界]] |
| 构建与验证 | Maven、vue-tsc、Vite、Vitest、GitHub Actions | 构建文件与工作流 |

依赖更新时修改本表；精确安装版本查 lock 文件，安装条件看 [安装教程](../../docs/INSTALL.md)。三端概览只链接本页，避免维护多份版本表。
