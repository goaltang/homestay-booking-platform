# 功能模块文档规范

这是 `功能模块-*.md` 的唯一模板，根目录 AGENTS.md 引用本页。原“功能模块文档模板”和“_文档规范模板”合并到这里。

## 写作原则

1. 正文只写已实现能力；计划、待办与未验证推断放方案或任务系统。
2. 功能按用户操作组织；页面、接口和数据模型放在后面。
3. 功能、路由、接口、字段、状态优先使用表格。
4. 组件用树形缩进；实现记录保留关键变化和依据，不贴大量代码。
5. 技术栈、完整安装和共享机制使用链接，不维护多份。
6. 简历和面试表达归入本地求职准备。
7. 不补写不存在的实现或测试结果；没有历史证据就不填“通过”。

## 模板

新增或重写正文时按以下顺序组织。不适用的内容说明原因；第六、七章仅在有特殊机制或历史记录时保留。

## 核对要求

| 核对项 | 要求 |
|---|---|
| 实现状态 | 对照代码，文件存在不能证明端到端流程通过 |
| 权限 | 谁能执行，是否校验订单或资源归属 |
| 路由和接口 | 查 Router 和 Controller |
| 状态和金额 | 实际来源、计算口径与边界 |
| 验证证据 | 日期、范围和结果，旧绿勾不代表本轮测试 |
| 链接 | 移动或改章节后检查有效性 |
