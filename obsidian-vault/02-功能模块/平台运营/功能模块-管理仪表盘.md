# 管理仪表盘

> 管理后台首页的数据概览。路由：`/dashboard` | 权限：管理员。通知的功能、接口和组件统一见 [[功能模块-通知中心]]。

## 一、功能清单

### 1.1 用户可见功能

| 操作 | 当前展示 |
|---|---|
| 看指标 | 房源总数、订单总数、用户总数、今日订单 |
| 看订单趋势 | 折线图，可切换时间范围 |
| 看房源分布 | 省份饼图，无数据时显示占位 |
| 刷新 | 并行请求总览、订单趋势与房源分布 |

本页不再维护一套管理员通知说明。

## 二、核心业务规则

| 内容 | 当前口径 |
|---|---|
| 总数卡片 | statistics.total 的 homestays、orders、users |
| 今日订单 | statistics.today.newOrders |
| 趋势字段 | calcTrend 计算差值 / 昨日基数，昨日为 0 不显示 |
| 趋势限制 | 前三张实际比较累计总数与昨日新增，不能解读为严格日增长率 |
| 权限 | AdminStatisticsController 的 ADMIN 角色校验 |

## 三、页面与组件

### 3.1 路由

| 路径 | 组件 | 使用者 |
|---|---|---|
| /dashboard | homestay-admin/src/views/dashboard/index.vue | 管理员 |

### 3.2 组件结构

```text
dashboard/index.vue
├── 问候与刷新
├── 四张指标卡片
└── 图表
    ├── 订单趋势
    └── 房源省份分布
```

### 3.3 状态管理

页面维护 loading、指标与 ECharts，Promise.all 请求三组数据；卸载时释放图表与 resize 监听。

## 四、后端接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/admin/statistics | total、period、today、yesterday |
| GET | /api/admin/statistics/order-trend | 订单趋势 |
| GET | /api/admin/statistics/homestay-distribution | 房源分布 |

其他统计接口属于统计分析模块，不在本页重复维护。

## 五、数据模型

展示统计服务读取业务数据后产生的聚合响应，不新增独立持久化表。

## 六、实时同步 / 特殊机制

ECharts 按需注册 LineChart、PieChart 等组件。刷新使用 HTTP，不使用通知 WebSocket 更新指标。

## 七、实现记录

| 日期 | 内容 | 依据 |
