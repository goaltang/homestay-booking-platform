# 入住退房模块

> [!info] 模块概述
> 入住退房模块管理订单从支付完成到最终结算的完整履约流程，包括入住凭证生成、自助入住/退房、押金操作、额外费用处理和最终结算确认。

## 涉及用户端

- **C 端用户/客人** — 查看入住凭证、自助入住、确认到达、自助退房
- **房东** — 设置准备入住、办理入住/退房、押金操作、额外费用、确认结算
- **管理员** — 协助办理入住退房、争议处理

## 功能清单

### 1. 入住准备（房东）
- **设置准备入住** — 订单支付后，房东生成入住凭证（入住码、门锁密码、密钥箱密码、位置描述）
- **取消准备入住** — 退回已生成的凭证

### 2. 入住凭证
- **凭证内容** — 入住码、门锁密码、密钥箱密码、房源位置描述、有效期
- **查看权限** — 房东和订单客人均可查看

### 3. 办理入住
- **房东/管理员手动办理** — 将订单状态从 `READY_FOR_CHECKIN` 转为 `CHECKED_IN`
- **客人自助入住** — 输入入住码完成自助入住
- **客人确认到达** — 客人主动确认已到达房源

### 4. 办理退房
- **房东/管理员手动办理** — 将订单状态从 `CHECKED_IN` 转为 `CHECKED_OUT`
- **客人自助退房** — 客人主动发起退房

### 5. 押金与额外费用
- **押金操作** — 扣押、退还、部分扣除（需记录原因）
- **额外费用** — 退房时添加额外费用（如清洁费、物品损坏赔偿）

### 6. 确认结算
- **最终结算** — 将订单状态从 `CHECKED_OUT` 转为 `COMPLETED`，触发收益结算

## 入住退房状态流转

```
已支付 (PAID)
    ↓ 房东设置准备入住
准备入住 (READY_FOR_CHECKIN)
    ↓ 办理入住（手动/自助/确认到达）
已入住 (CHECKED_IN)
    ↓ 办理退房（手动/自助）
已退房 (CHECKED_OUT)
    ↓ 确认结算
已完成 (COMPLETED)
```

## 后端 API

### 入住接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/orders/{id}/prepare-checkin` | 房东设置准备入住（生成凭证） |
| GET | `/api/orders/{id}/checkin-credential` | 获取入住凭证 |
| PUT | `/api/orders/{id}/check-in` | 手动办理入住 |
| POST | `/api/orders/checkin/self` | 客人自助入住（传入入住码） |
| POST | `/api/orders/{id}/confirm-arrival` | 客人确认到达 |
| PUT | `/api/orders/{id}/cancel-prepare` | 取消准备入住 |
| GET | `/api/orders/{id}/checkin-record` | 获取入住记录 |

### 退房接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/orders/{id}/check-out` | 手动办理退房 |
| POST | `/api/orders/{id}/checkout/self` | 客人自助退房 |
| POST | `/api/orders/{id}/deposit` | 押金操作（扣押/退还/部分扣除） |
| GET | `/api/orders/{id}/checkout-record` | 获取退房记录 |
| PUT | `/api/orders/{id}/checkout/settle` | 确认最终结算 |
| PUT | `/api/orders/{id}/extra-charges` | 更新额外费用 |

## 入住凭证数据结构

```typescript
interface CheckInCredential {
  checkInCode: string        // 入住码（自助入住用）
  doorPassword: string       // 门锁密码
  lockboxCode: string        // 密钥箱密码
  locationDescription: string // 房源位置描述（如：3楼左转302室）
  validFrom: string          // 凭证有效期开始
  validUntil: string         // 凭证有效期结束
}

// 入住记录
interface CheckInRecord {
  id: number
  orderId: number
  checkInMethod: 'SELF_SERVICE' | 'MANUAL' | 'CODE'
  checkedInAt: string
  checkInOperatorType: 'HOST' | 'ADMIN' | 'SYSTEM' | 'SELF_SERVICE'
  checkInCode: string
  doorPassword: string
  lockboxCode: string
  status: 'ACTIVE' | 'EXPIRED' | 'CANCELLED'
}
```
