# 文件图片管理模块

> [!info] 模块概述
> 文件图片管理模块提供统一的文件上传、存储、下载和删除服务。支持头像、房源图片、评价图片、房东证件等多种文件类型，采用本地文件系统存储（`uploads/` 目录）。

## 涉及用户端

- **C 端用户** — 上传头像、评价图片
- **房东** — 上传房源图片、房东证件
- **管理后台** — 上传各类系统图片

## 功能清单

### 1. 通用文件上传
- **单文件上传** — 上传单个文件，指定类型（avatar / homestay / review / common）
- **多文件上传** — 批量上传多个文件
- **文件类型隔离** — 不同类型文件存储在不同子目录

### 2. 文件下载与访问
- **文件下载** — 通过 `/api/files/{type}/{fileName}` 访问文件
- **Content-Type 自动识别** — 根据文件扩展名返回正确的 MIME 类型
- **内联展示** — 图片等文件可直接在浏览器中预览

### 3. 文件删除
- **单文件删除** — 删除指定文件
- **头像特殊处理** — 上传头像时自动更新用户数据库中的头像 URL

### 4. 房源图片管理
- **单张上传** — 为指定房源上传单张图片
- **批量上传** — 为指定房源一次性上传多张图片
- **图片列表** — 获取某个房源的所有图片
- **单张删除** — 删除指定图片
- **全部删除** — 删除某个房源的所有图片

### 5. 文件类型分类

| 类型 | 存储路径 | 用途 |
|------|---------|------|
| `avatar` | `uploads/avatar/` | 用户/房东头像 |
| `homestay` | `uploads/homestay/` | 房源封面和详情图片 |
| `review` | `uploads/review/` | 评价图片 |
| `common` | `uploads/common/` | 其他通用文件 |

## 后端 API

### 通用文件

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/files/upload` | 单文件上传（参数：file, type） |
| POST | `/api/files/uploadMultiple` | 多文件上传 |
| GET | `/api/files/{type}/{fileName}` | 下载/访问文件 |
| DELETE | `/api/files/{type}/{fileName}` | 删除文件 |

### 房源图片

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/homestay-images/upload` | 上传单张房源图片 |
| POST | `/api/homestay-images/upload-multiple` | 批量上传房源图片 |
| GET | `/api/homestay-images/homestay/{homestayId}` | 获取房源图片列表 |
| DELETE | `/api/homestay-images/{imageId}` | 删除指定图片 |
| DELETE | `/api/homestay-images/homestay/{homestayId}` | 删除房源所有图片 |

## 前端组件

| 组件 | 路径 | 说明 |
|------|------|------|
| `AvatarUpload.vue` | `components/AvatarUpload.vue` | 头像上传组件（支持裁剪预览） |

## 上传响应格式

```typescript
interface FileUploadResponse {
  status: 'success' | 'error'
  fileName: string
  fileType: string
  fileSize: number
  downloadUrl: string
  data: {
    fileName: string
    url: string
  }
}
```

## 存储结构

```
uploads/
├── avatar/        # 头像文件
├── homestay/      # 房源图片
├── review/        # 评价图片
└── common/        # 其他文件
```

## 安全与限制

- 文件上传需登录认证（`@PreAuthorize("isAuthenticated()")`）
- 文件名使用 UUID 重命名，避免冲突和目录遍历
- 头像上传后自动同步更新用户表 `avatar` 字段
