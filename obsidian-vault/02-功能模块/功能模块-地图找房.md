# 地图找房模块

> [!info] 模块概述
> 地图找房是前端核心功能之一，基于高德地图 JSAPI 实现交互式地图浏览与房源搜索。支持地图视野搜索、周边搜索、地标搜索、聚合模式等多种搜索模式，并提供完整的筛选条件和移动端适配。

## 页面路由

| 路由路径 | 组件 | 说明 |
|---------|------|------|
| `/map-search` | `MapSearch.vue` | 地图找房主页面 |

## 功能清单

### 1. 地图视野搜索（Normal 模式）
- 地图拖动/缩放后自动触发搜索（防抖 500ms）
- 仅显示当前地图视野内的房源
- 支持「仅看当前视野」开关切换
- 地图标记 price-marker 显示房源价格
- 标记防重叠：价格相近的标记自动垂直堆叠偏移

### 2. 周边搜索（Nearby 模式）
- 基于用户当前 GPS 定位搜索附近房源
- 支持 1-20km 半径调节
- 地图中心显示蓝色圆点标记 + 半径圆形覆盖层
- 搜索框快捷入口「我的当前位置」

### 3. 地标搜索（Landmark 模式）
- 输入地标/景点/商圈名称，基于高德 POI 数据定位
- 支持 AMap.Autocomplete 智能联想提示
- 以地标为中心进行半径搜索
- 搜索框显示「地标：XXX」上下文卡片

### 4. 聚合模式（Cluster 模式）
- 放大到一定级别时自动切换为单房源标记
- 缩小级别时显示聚合点，展示区域内房源数量
- 聚合点大小随数量动态变化

### 5. 筛选条件
- **地区**：省市区级联选择器（element-china-area-data）
- **日期**：入住/退房日期范围
- **人数**：入住人数（1-20人）
- **价格区间**：最低价/最高价输入
- **搜索关键词**：目的地、地标、景点等

### 6. 列表与地图联动
- 左侧房源列表与右侧地图标记双向联动
- 列表 hover → 标记高亮（蓝色边框）
- 列表点击 → 地图居中定位并打开信息窗
- 标记点击 → 列表自动滚动到对应卡片
- 移动端支持手势拖拽展开/收起列表

### 7. URL 查询参数同步
- 所有搜索状态（位置、筛选、地图视野）同步到 URL query
- 页面刷新后自动恢复之前的搜索状态
- 支持分享链接直接打开对应地图视图

## 前端架构

### 核心 Composables

```
useMapSearch          # 地图找房核心逻辑（地图初始化、标记管理、搜索调度）
useMapSearchState     # 搜索状态机（normal/nearby/landmark 模式切换）
useMapSearchQuerySync # URL query 与表单状态双向同步
useMap                # 通用地图封装（详情页等复用）
```

### 地图服务

```
amapLoader.ts   # 高德 JSAPI 单例加载器（缓存 Promise）
amapConfig.ts   # 高德配置（Key、安全码、插件列表）
mapService.ts   # POI 联想、地理编码、静态地图、距离计算
```

### 主要组件

| 组件 | 路径 | 说明 |
|------|------|------|
| `MapSearch.vue` | `views/MapSearch.vue` | 地图找房主页面（左列表 + 右地图布局） |
| `MapHomestayCard.vue` | `components/homestay/MapHomestayCard.vue` | 地图列表专用房源卡片 |
| `LocationInfo.vue` | `components/homestay/LocationInfo.vue` | 房源位置信息展示 |

### 搜索模式状态机

```
normal   →  地图视野搜索（默认）
   ↑
nearby   →  当前位置/地图中心周边搜索
   ↑
landmark →  指定地标周边搜索
```

切换模式时：
- `normal` → `nearby`：保存当前 normal 快照，定位到用户位置
- `normal` → `landmark`：保存快照，以地标为中心搜索
- `nearby/landmark` → `normal`：恢复快照，恢复原有地图视野

## 后端 API

### 地图搜索相关接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/homestays/map-search` | 地图视野内房源搜索（需传入边界坐标） |
| POST | `/api/homestays/map-clusters` | 获取地图聚合点数据 |
| POST | `/api/homestays/nearby` | 周边房源搜索（需传入中心坐标+半径） |
| POST | `/api/homestays/landmark-search` | 地标周边房源搜索 |
| GET  | `/api/map/poi-suggestions` | 高德 POI 联想提示（后端代理，带 Redis 缓存） |
| GET  | `/api/map/geocode` | 地址地理编码（后端代理，带 Redis 缓存） |

### 请求参数示例

```typescript
interface HomestaySearchRequest {
  // 基础筛选
  keyword?: string;
  provinceCode?: string;
  cityCode?: string;
  districtCode?: string;
  minPrice?: number;
  maxPrice?: number;
  minGuests?: number;
  checkInDate?: string;
  checkOutDate?: string;
  
  // 地图视野（map-search 必需）
  northEastLat?: number;
  northEastLng?: number;
  southWestLat?: number;
  southWestLng?: number;
  
  // 周边/地标搜索（nearby/landmark 必需）
  latitude?: number;
  longitude?: number;
  radiusKm?: number;
}
```

## 高德地图集成

### 密钥配置

| 环境变量 | 用途 |
|---------|------|
| `VITE_AMAP_API_KEY` | 前端 JSAPI Key（地图加载） |
| `VITE_AMAP_SECURITY_JS_CODE` | JSAPI 安全码（新 Key 必需） |
| `VITE_AMAP_WEB_SERVICE_KEY` | Web Service Key（静态地图等） |
| `AMAP_API_KEY` | 后端 Web Service Key（地理编码/POI） |

### 加载的插件

- `AMap.Geocoder` — 地理编码/逆编码
- `AMap.AutoComplete` — POI 输入联想
- `AMap.PlaceSearch` — 地点搜索

### JSAPI 加载优化

`amapLoader.ts` 使用单例模式缓存 `AMapLoader.load()` 的 Promise，确保：
- SDK 只加载一次
- 多个组件（useMapSearch、mapService）共享同一实例
- 安全配置 `window._AMapSecurityConfig` 在首次加载前自动注入

## 数据流

```
用户操作（拖拽地图/选择筛选/输入地标）
    ↓
MapSearch.vue 构建 filters
    ↓
useMapSearchState 确定 searchMode
    ↓
useMapSearch 调用对应搜索函数
    ├─ normal   → mapSearchHomestays()    (带视野边界)
    ├─ nearby   → getNearbyHomestays()    (带中心坐标+半径)
    └─ landmark → landmarkSearchHomestays() (带地标坐标+半径)
    ↓
后端 HomestaySearchService 执行搜索
    ↓
前端过滤保留有坐标的房源 → 更新标记
    ↓
applyMarkerAntiOverlap() 防重叠处理
    ↓
updateSearchContextOverlays() 更新中心标记和半径圆
```

## 缓存策略

后端对高德 API 调用做了 Redis 缓存：

| 缓存类型 | Key 前缀 | TTL |
|---------|---------|-----|
| 地理编码结果 | `map:geocode:` | 30 天 |
| POI 联想结果 | `map:poi:` | 7 天 |

## 降级处理

- 房源无坐标：过滤不显示在地图上（后端数据需先通过 GeocodingService 补充坐标）
- 高德 API 失败：返回空结果，前端展示空状态提示
- 定位失败：提示用户检查浏览器权限设置
- 地图加载失败：显示重试按钮，点击重新初始化
