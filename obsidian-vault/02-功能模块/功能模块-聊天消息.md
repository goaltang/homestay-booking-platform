# 聊天消息模块

> [!info] 模块概述
> 聊天消息模块为平台用户提供即时通讯能力，支持客人与房东之间的一对一会话沟通。基于 REST API + 轮询模式实现消息收发、会话管理和未读计数。

## 涉及用户端

- **C 端用户/客人** — 发起咨询、与房东沟通入住细节
- **房东** — 回复客人咨询、处理入住相关问题

## 功能清单

### 1. 会话管理
- **会话列表** — 按最后消息时间倒序展示所有会话
- **创建会话** — 从房源详情页发起咨询，创建与房东的会话
- **会话详情** — 查看会话信息和消息历史

### 2. 消息收发
- **发送消息** — 文本消息发送
- **消息列表** — 分页加载历史消息（按时间倒序）
- **消息已读** — 标记会话内所有消息为已读

### 3. 未读计数
- **总未读数** — 获取所有会话的未读消息总数
- **会话级未读** — 每个会话显示未读消息数

## 业务流程

```
客人浏览房源详情页
    ↓
点击「咨询房东」→ POST /api/chat/conversations（传入房源ID和房东ID）
    ↓
进入聊天对话框
    ↓
发送消息 → POST /api/chat/conversations/{id}/messages
    ↓
房东收到消息（轮询或推送通知）
    ↓
房东回复 → 同上
    ↓
客人标记已读 → PUT /api/chat/conversations/{id}/read
```

## 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/chat/conversations` | 获取会话列表（分页） |
| GET | `/api/chat/conversations/{id}` | 获取会话详情 |
| POST | `/api/chat/conversations` | 创建会话（传入 homestayId, hostId） |
| GET | `/api/chat/conversations/{id}/messages` | 获取会话消息（分页） |
| POST | `/api/chat/conversations/{id}/messages` | 发送消息 |
| PUT | `/api/chat/conversations/{id}/read` | 标记会话已读 |
| GET | `/api/chat/unread-count` | 获取总未读消息数 |

## 数据结构

```typescript
// 会话
interface Conversation {
  id: number

  hostId: number           // 房东 ID
  guestId: number          // 客人 ID

  unreadCount: number      // 未读消息数

// 消息
interface Message {
  id: number
  conversationId: number
  senderId: number
  content: string
  isRead: boolean
  readAt?: string

// 会话 DTO（前端展示用）
interface ConversationDTO {
  id: number
  homestayTitle: string
  homestayCoverImage: string
  otherPartyName: string
  otherPartyAvatar: string
  lastMessage: string
  lastMessageAt: string
  unreadCount: number
}
```

## 技术实现

### 消息推送
当前采用 **客户端轮询** 模式：
- 前端定期轮询 `/api/chat/unread-count` 获取未读数
- 进入聊天窗口时轮询 `/api/chat/conversations/{id}/messages` 获取新消息

### 数据持久化
- `conversations` 表 — 会话基础信息
- `messages` 表 — 消息内容、发送者、已读状态
- 数据库索引优化 — 按 `conversation_id + created_at` 复合索引加速消息查询
