# 房源搜索

> 用户主动搜索可预订房源的核心模块。路由：`/`（首页）、`/homestays`（列表页） | 权限：匿名可访问

## 二、核心业务规则

### 2.1 搜索条件判定规则

系统使用统一的 11 维度判定，任意维度有值即视为「有搜索条件」：

| 维度 | 判定条件 | 触发场景 |
|------|----------|----------|
| 关键词 | `keyword.trim() !== ''` | 用户输入搜索词 |
| 地区 | `selectedRegion.length > 0` | 选择省/市/区县 |
| 入住日期 | `checkIn !== null` | 选择入住日期 |
| 退房日期 | `checkOut !== null` | 选择退房日期 |
| 人数 | `guestCount > 1` | 人数大于默认值 1 |
| 房源类型 | `propertyType !== null` | 选择房型 |
| 最低价格 | `minPrice !== null` | 输入最低价 |
| 最高价格 | `maxPrice !== null` | 输入最高价 |
| 设施 | `amenities.length > 0` | 勾选至少一项设施 |
| 最低评分 | `minRating !== null` | 选择最低评分 |
| 分组 ID | `groupId !== null` | 通过分组进入搜索 |

### 2.2 后端过滤规则

| 规则 | 实现方式 |
|------|----------|
| 人数过滤 | `maxGuests >= minGuests`（JPA 条件 / ES filter） |
| 日期可用性过滤 | 当且仅当 `checkInDate` 和 `checkOutDate` 同时存在时触发。排除存在重叠已确认/已支付订单的房源。SQL 语义：`NOT EXISTS` 重叠区间且状态为 `CONFIRMED` 或 `PAID` 的订单 |
| 设施过滤 | JPA 为 ` amenities CONTAINS ALL `；ES 为 `terms` 查询（AND 语义） |
| 关键词过滤 | 非空时优先走 ES 全文检索；ES 不可用时回退 JPA `LIKE` 匹配（标题、描述、地址） |
| 排序 | 支持多字段排序，格式 `field,asc;field2,desc`，优先于 `sortBy+sortDirection` |

### 2.3 搜索链路状态

```
无搜索条件 ──→ 展示热门/推荐房源
    ↓
有搜索条件 ──→ 调用 /api/homestays/search
    ↓
有关键词且 ES 可用 ──→ Elasticsearch 全文检索
    ↓
无关键词或 ES 不可用 ──→ JPA 条件查询
    ↓
统一补充日期可用性过滤 ──→ DTO 组装返回
```

## 三、页面与组件

### 3.1 路由

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | `Home.vue` | 首页搜索入口，居中展示 SearchBar |
| `/homestays` | `HomestayListView.vue` | 房源列表和搜索结果页 |

### 3.2 组件结构

```
HomestayListView.vue
├── SearchBar.vue
│   ├── SearchInput              # 关键词输入 + 搜索建议下拉
│   ├── RegionSelector           # 省市区级联选择（element-china-area-data）
│   ├── DateRangePicker          # 入住/退房日期范围
│   └── GuestPicker              # 成人/儿童/婴儿自定义选择器（自定义 popover）
├── FilterBar
│   ├── PriceFilter              # 最低/最高价格输入
│   ├── PropertyTypeFilter       # 房源类型选择
│   ├── AmenityFilter            # 设施多选
│   └── SortSelector             # 排序方式下拉
├── ActiveFilterChips            # 已选筛选条件标签，可逐个移除
├── HomestayCardGrid
│   └── HomestayCard             # 房源卡片（图片、标题、价格、评分、位置）
├── EmptyState                   # 无结果提示
├── ErrorState（el-result）      # 网络/超时/服务端错误，含重试和重置按钮
└── Pagination                   # 分页器
```

### 3.3 状态管理

`search.ts`（Pinia store）：

| 状态/方法 | 说明 |
|-----------|------|
| `searchParams` | 搜索参数对象，含关键词、地区、日期、人数、价格、房型、设施、评分、分组等 |
| `hasSearchConditions()` | 11 维度搜索条件判定函数 |
| `isSearchMode` / `hasActiveSearch` | 计算属性，基于 `hasSearchConditions()` |
| `syncFromUrl()` | 从 URL query 解析并恢复搜索参数 |
| `syncToUrl()` | 将当前搜索参数写入 URL query |
| `parseError()` | 错误分类：网络错误 / 请求超时 / 服务端错误 |

## 四、后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/homestays/search` | 房源搜索，返回分页结果列表 |
| POST | `/api/homestays/map-search` | 地图视野内搜索（需边界坐标） |
| POST | `/api/homestays/map-clusters` | 地图聚合点数据 |
| POST | `/api/homestays/nearby` | 周边搜索（需中心坐标+半径） |
| POST | `/api/homestays/landmark-search` | 地标周边搜索 |
| POST | `/api/tracking/search` | 搜索行为埋点（匿名可访问） |

### 4.1 核心 Service

`HomestaySearchServiceImpl`：

| 路径 | 说明 |
|------|------|
| JPA 搜索 | `CriteriaBuilder` 动态条件查询 + `NOT EXISTS` 日期可用性子查询 |
| ES 搜索 | `ElasticsearchClient` 全文检索 + `bool` filter + `sort` |
| 降级 | ES 连接异常或查询失败时，捕获异常并回退到 JPA 路径 |

### 5.2 DTO

```typescript
interface HomestaySearchRequest {
  keyword?: string
  provinceCode?: string
  cityCode?: string
  districtCode?: string
  minPrice?: number
  maxPrice?: number
  minGuests?: number          // 对应后端 maxGuests >= minGuests
  propertyType?: string
  requiredAmenities?: string[]
  checkInDate?: string        // yyyy-MM-dd
  checkOutDate?: string       // yyyy-MM-dd，两者同时存在才触发日期过滤
  latitude?: number
  longitude?: number
  radiusKm?: number
  northEastLat?: number
  northEastLng?: number
  southWestLat?: number
  southWestLng?: number

  sortDirection?: 'asc' | 'desc'

}
```

## 六、实时同步 / 特殊机制

| 机制 | 说明 |
|------|------|
| ES 索引同步 | 房东端创建/更新/删除房源、管理员审核/强制下架/批量操作后，异步同步到 `homestay_index` |
