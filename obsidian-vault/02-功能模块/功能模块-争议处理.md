# 争议处理模块

> [!info] 模块概述
> 争议处理模块用于记录和管理订单履约过程中产生的纠纷，支持房东发起争议、管理员查看和仲裁。争议通常涉及退款请求、入住问题、物品损坏等场景。

## 涉及用户端

- **房东** — 发起争议、查看自己提交的争议记录
- **管理员** — 查看所有争议、进行仲裁裁决
- **系统** — 自动关联订单生成争议记录

## 功能清单

### 1. 争议记录
- **争议关联订单** — 每个争议对应一个具体订单
- **争议原因** — 详细描述争议事由
- **发起人与时间** — 记录争议由谁发起、何时发起

### 2. 房东端
- **我的争议列表** — 查看自己发起的所有争议记录
- **争议详情** — 查看单个争议的完整信息
- **发起争议** — 在订单出现问题时提交争议（通常在入住退房流程中触发）

### 3. 管理员端
- **全部争议列表** — 查看平台所有争议记录
- **按订单筛选** — 根据订单 ID 查找对应争议
- **仲裁裁决** — 对争议做出 APPROVED（批准退款）或 REJECTED（拒绝退款）裁决
- **仲裁备注** — 记录裁决理由

## 争议状态流转

```
争议发起
    ↓
待处理（PENDING）
    ↓
管理员仲裁 → APPROVED（批准退款）/ REJECTED（拒绝退款）
```

## 后端 API

### 房东端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/host/disputes` | 获取当前房东的争议列表 |
| GET | `/api/host/disputes/{orderId}` | 获取争议详情（验证归属权） |

### 管理员端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/disputes` | 获取所有争议记录 |
| GET | `/api/admin/disputes/{orderId}` | 根据订单 ID 获取争议详情 |

## 数据结构

```typescript
// 争议记录
interface DisputeRecord {
  id: number
  orderId: number
  disputeReason: string      // 争议原因描述
  raisedBy: number           // 发起人用户ID
  raisedAt: string           // 发起时间
  resolution?: string        // 仲裁结果: APPROVED / REJECTED
  resolvedBy?: number        // 仲裁人ID
  resolvedAt?: string        // 仲裁时间
  resolutionNote?: string    // 仲裁备注
  createdAt: string
  updatedAt: string
}
```

## 前端页面

争议处理功能主要嵌入在以下页面中：
- `OrderManage.vue` — 房东订单管理中可查看/发起争议
- `HostOrderDetail.vue` — 订单详情页展示争议记录
- Admin 后台的「争议管理」页面（system/DisputeManage.vue）
