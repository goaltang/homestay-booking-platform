# 认证权限模块

> [!info] 模块概述
> 认证权限模块负责平台用户的注册、登录、密码管理和身份鉴权。基于 Spring Security + JWT 实现无状态认证，支持用户、房东、管理员多角色权限控制。

## 涉及用户端

- **C 端用户** — 注册、登录、修改密码、查看个人信息
- **房东** — 同 C 端用户，额外支持成为房东的角色升级
- **管理员** — 独立的 Admin 登录入口

## 功能清单

### 1. 用户注册
- 用户名/邮箱/密码注册
- 用户名唯一性校验
- 邮箱唯一性校验
- 注册成功后自动登录，返回 JWT Token

### 2. 用户登录
- 用户名 + 密码登录
- 登录成功后返回 JWT Token 和用户信息
- Token 包含用户角色信息（ROLE_USER / ROLE_HOST / ROLE_ADMIN）

### 3. 密码管理
- **忘记密码** — 通过邮箱发送密码重置链接
- **重置密码** — 使用重置令牌设置新密码

### 4. 用户信息
- **获取当前用户** — 通过 Token 获取登录用户信息（含角色权限）
- **获取指定用户** — 根据用户名查询用户信息

### 5. 角色权限
- **用户（USER）** — 浏览房源、下单、收藏、评价
- **房东（HOST / LANDLORD）** — 管理房源、处理订单、查看收益
- **管理员（ADMIN）** — 全平台管理、审核、系统配置

## 认证流程

```
用户注册/登录
    ↓
后端验证用户名密码
    ↓
生成 JWT Token（含用户ID、用户名、角色）
    ↓
前端存储 Token（localStorage）
    ↓
后续请求携带 Authorization: Bearer <token>
    ↓
JwtAuthenticationFilter 校验 Token 有效性
    ↓
Spring Security 根据角色控制接口访问权限
```

## 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 用户注册 |
| POST | `/api/auth/login` | 用户登录 |
| POST | `/api/auth/forgot-password` | 忘记密码（发送重置邮件） |
| POST | `/api/auth/reset-password` | 重置密码 |
| GET | `/api/auth/current` | 获取当前登录用户信息（含角色权限） |
| GET | `/api/auth/user-info` | 获取指定用户信息 |
| GET | `/api/auth/check-username` | 检查用户名是否存在 |
| GET | `/api/auth/check-email` | 检查邮箱是否存在 |

## JWT Token 结构

```typescript
interface AuthResponse {
  token: string          // JWT Token
  id: number
  username: string
  email: string
  phone?: string
  realName?: string
  avatar?: string
  role: 'USER' | 'HOST' | 'LANDLORD' | 'ADMIN'
  authorities: string[]  // Spring Security 权限列表
}
```

## 接口权限控制示例

```java
// 仅房东可访问
@PreAuthorize("hasAnyRole('HOST', 'LANDLORD')")

// 仅管理员可访问
@PreAuthorize("hasRole('ADMIN')")

// 任意认证用户
@PreAuthorize("isAuthenticated()")
```
