# 公告通知模块

> [!info] 模块概述
> 公告通知模块为平台提供系统级消息发布能力。管理员可在后台创建、发布和管理公告，C 端用户可在首页或公告页面查看已发布的平台公告。

## 涉及用户端

- **C 端用户** — 查看已发布的系统公告列表和详情
- **管理员** — 创建、编辑、发布、下线、删除公告

## 功能清单

### 1. 用户端公告
- **公告列表** — 按优先级和发布时间倒序展示已发布公告
- **分类筛选** — 按公告分类筛选（如活动、维护、规则更新）
- **公告详情** — 查看单条公告的完整内容

### 2. 管理员端公告管理
- **公告列表** — 查看所有公告（含草稿、已发布、已下线）
- **状态筛选** — 按状态筛选公告
- **创建公告** — 填写标题、内容、分类、优先级
- **编辑公告** — 修改未发布的公告内容
- **发布公告** — 将草稿或下线的公告转为发布状态
- **下线公告** — 将已发布公告下线（用户不可见）
- **删除公告** — 永久删除公告

### 3. 操作日志
- 公告的创建、更新、发布、下线、删除均记录操作日志
- 记录操作人、操作类型、IP 地址、操作结果

## 公告生命周期

```
DRAFT（草稿）→ PUBLISHED（已发布）→ OFFLINE（已下线）
     ↑______________________________|
```

## 后端 API

### 用户端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/announcements` | 获取已发布公告列表（支持分类筛选） |
| GET | `/api/announcements/{id}` | 获取公告详情 |

### 管理员端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/announcements` | 获取所有公告（支持状态筛选） |
| GET | `/api/admin/announcements/{id}` | 获取公告详情 |
| POST | `/api/admin/announcements` | 创建公告 |
| PUT | `/api/admin/announcements/{id}` | 更新公告 |
| DELETE | `/api/admin/announcements/{id}` | 删除公告 |
| POST | `/api/admin/announcements/{id}/publish` | 发布公告 |
| POST | `/api/admin/announcements/{id}/offline` | 下线公告 |

## 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| Admin 公告管理 | `system/Announcement.vue` | 管理员公告 CRUD 页面 |
| 首页公告栏 | `Home.vue` | 首页展示最新公告 |

## 数据结构

```typescript
interface Announcement {
  id: number
  title: string
  content: string
  category?: string       // 公告分类
  priority: number        // 优先级（数字越大越靠前）
  status: 'DRAFT' | 'PUBLISHED' | 'OFFLINE'
  publisherId?: number
  publisherName?: string
  publishedAt?: string
  createdAt: string
  updatedAt: string
}
```
