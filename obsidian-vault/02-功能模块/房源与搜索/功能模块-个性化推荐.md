# 个性化推荐

> 在首页和详情页展示热门、精选、个性化或相似房源。路由：`/`、`/homestays/:id` | 权限：个性化推荐需要登录，兼容接口只能请求本人 ID。

## 一、功能清单

### 1.1 用户可见功能

| 操作 | 当前行为 |
|---|---|
| 看热门 / 精选 | 首页请求对应推荐接口 |
| 看猜你喜欢 | 登录用户取得自己的个性化结果 |
| 看相似房源 | 详情页按当前房源取得相似推荐 |
| 看位置推荐 | 按省市取得候选结果 |

### 1.2 系统功能

| 功能 | 当前行为 |
|---|---|
| 记录行为 | 页面记录浏览、搜索、点击；业务服务记录收藏与下单 |
| 聚合画像 | 定时聚合城市、房型、设施和价格偏好 |
| 排序 | 读取画像，合并订单与收藏偏好，评分和多样性处理 |

## 二、核心业务规则

| 规则 | 当前行为 |
|---|---|
| 候选房源 | 个性化服务读取 ACTIVE 房源 |
| 偏好来源 | applyProfilePreferences 读取画像，再合并订单与收藏 |
| 画像不足 | 尝试聚合，保留默认偏好 |
| 结果不足 | 放宽过滤、合并候选、去重，再做多样性处理 |
| 本人访问 | /personalized/me 使用认证 ID；/{userId} 不一致返回 403 |
| 效果 | 本页没有实测点击率或转化率，不能宣称效果提升 |

## 三、页面与组件

### 3.1 路由

| 路径 | 页面 | 内容 |
|---|---|---|
| / | Home.vue | 热门、精选、猜你喜欢 |
| /homestays/:id | HomestayDetail.vue | 相似推荐 |

### 3.2 组件结构

```text
Home.vue
├── RecommendedHomestays.vue
├── PopularHomestays.vue
└── PersonalizedRecommendations.vue
HomestayDetail.vue
└── 相似推荐区域
```

### 3.3 状态管理

推荐组件维护请求与展示状态，埋点封装在 src/api/tracking.ts。算法与埋点机制见 [[技术设计-搜索与推荐]]。

## 四、后端接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/recommendations/popular | 热门，limit 或分页 |
| GET | /api/recommendations/recommended | 精选，limit 或分页 |
| GET | /api/recommendations/personalized/me | 当前用户结果 |
| GET | /api/recommendations/personalized/{userId} | 本人 ID 兼容入口 |
| GET | /api/recommendations/location | 省市推荐 |
| GET | /api/recommendations/similar/{homestayId} | 相似推荐 |
| POST | /api/recommendations/custom | 条件推荐 |
| POST | /api/recommendations/refresh-cache | 刷新缓存 |
| POST | /api/tracking/view/{homestayId} | 浏览 |
| POST | /api/tracking/search | 搜索 |
| POST | /api/tracking/click/{homestayId} | 点击 |

## 五、数据模型

| 表 / DTO | 作用 | 关键字段 |
|---|---|---|
| user_behavior_event | 行为事件 | user_id、session_id、event_type、homestay_id、keyword、city_code |
| user_preference_profile | 画像 | preferred_city_json、preferred_type_json、preferred_amenity_json、min_price、max_price |
| HomestaySummaryDTO | 返回摘要 | 房源展示字段 |

## 六、实时同步 / 特殊机制

UserProfileAggregationJob 每小时处理最近 7 天活跃登录用户。页面、业务事件与画像读取入口见 [[技术设计-搜索与推荐]]。当前实现不属于机器学习模型训练。
