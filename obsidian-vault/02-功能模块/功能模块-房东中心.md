# 房东中心模块

> [!info] 模块概述
> 房东中心模块为平台房东提供一站式管理入口，包括房东资料管理、房源管理、订单管理、收益查看、评价管理和营销活动中心。与 Admin 后台的「房源管理」「订单管理」不同，房东中心完全从房东视角出发，只能操作自己的数据。

## 涉及用户端

- **房东（HOST / LANDLORD）** — 房源发布、订单处理、收益查看、营销活动

## 功能清单

### 1. 房东入驻
- **成为房东** — 普通用户一键升级为房东角色
- **房东资料** — 查看和编辑房东信息（联系方式、简介、收款账号）
- **证件上传** — 上传房东身份证件照片
- **头像管理** — 更新房东头像

### 2. 房东仪表盘
- **统计数据** — 总房源数、总订单数、总收入、平均评分
- **快捷入口** — 房源管理、订单管理、收益查看、营销活动
- **最近订单** — 待处理订单提醒

### 3. 房源管理（房东视角）
- **我的房源列表** — 分页查看自己发布的所有房源
- **房源选项** — 获取房源下拉选项（用于营销活动等场景）
- **新增/编辑房源** — 填写房源信息、上传图片、设置价格（复用 HomestayForm.vue）

### 4. 订单管理（房东视角）
- **我的订单列表** — 分页查看与自己房源关联的所有订单
- **按状态筛选** — 待支付、已支付、已入住、已完成等
- **订单详情** — 查看入住人信息、处理入住退房

### 5. 评价管理（房东视角）
- **我的评价列表** — 查看客人对自己房源的评价
- **评价回复** — 对评价进行官方回复

### 6. 收益与营销
- **收益管理** — 查看收益明细、趋势、结算（见 [[功能模块-支付与财务]]）
- **营销活动** — 创建折扣/限时抢购活动（见 [[功能模块-营销促销]]）

## 后端 API

### 房东信息

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/host/info` | 获取房东信息 |
| PUT | `/api/host/info` | 更新房东信息 |
| GET | `/api/host/profile` | 获取房东个人资料 |
| PUT | `/api/host/profile` | 更新房东个人资料 |
| POST | `/api/host/register` | 成为房东（角色升级） |
| POST | `/api/host/upload-document` | 上传房东证件 |

### 房东数据

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/host/statistics` | 房东统计数据 |
| GET | `/api/host/homestays` | 我的房源列表 |
| GET | `/api/host/homestay-options` | 房源下拉选项 |
| GET | `/api/host/orders` | 我的订单列表（支持状态筛选） |
| GET | `/api/host/reviews` | 我的评价列表 |
