# 房东日历

> 房东经营日期库存的统一工作台。支持月视图查看房源状态、批量调整可用性与价格、订单跳转、CSV 导出和 WebSocket 实时同步。
> 
> 路由：`/host/calendar` | 权限：`ROLE_HOST` / `ROLE_LANDLORD`

---

## 一、功能清单

### 1.1 日历查看

| 功能 | 说明 |
|------|------|
| 月视图 | 7×6 网格，展示当月及前后月日期 |
| 月份切换 | 上/下月箭头 + "本月"按钮 |
| 今日高亮 | 蓝色边框标识当天 |
| 状态色块 | 7 种状态以顶部边框色区分：可订(绿)、待确认(橙)、已订(蓝)、入住中(蓝)、已退房(蓝)、不可订(红)、锁定中(灰) |
| 价格展示 | 单房源模式下格子底部显示 ¥finalPrice，有原价时显示删除线 |
| 入住/退房标记 | 格子内显示小标签 |
| 多房源汇总 | 全部房源模式显示"X 套房源"，hover 弹出 tooltip 列出每套名称和状态 |
| 订单跳转 | 有订单的日期显示可点击链接，支持左键跳转和右键新标签页打开 |
| 交互方式 | 单日点击、鼠标拖拽选范围、键盘方向键+Enter、触摸设备 |
| 移动端适配 | 小屏幕下缩小格子、字体、横向滚动 |

### 1.2 工具栏

| 功能 | 说明 |
|------|------|
| 房源筛选 | `el-select-v2` 虚拟选择器，支持输入搜索，几千套房源不卡顿 |
| 刷新 | 重新拉取当前月份数据 |
| CSV 导出 | 导出当前月份日历数据为 CSV |

### 1.3 统计面板

展示当月数据汇总：可订 / 已订 / 待确认 / 不可订 / 入住 / 退房 数量 + 预计收入。

### 1.4 抽屉操作

点击日期或拖拽范围后打开右侧抽屉：

| 功能 | 说明 |
|------|------|
| 日期摘要 | 蓝色头部条展示选中日期范围和天数 |
| 状态统计 | 全部房源模式下显示该日各状态房源数量 |
| 房源卡片 | 只展示即将操作的房源，卡片带状态色左边框 |
| 调整状态 | 设为不可订 / 恢复可订，支持批量多选房源、填写原因和备注 |
| 调整价格 | 设置每日自定义价格，或清除价格恢复默认 |
| 批量保护 | 超过 7 天设为不可订时二次确认 |
| 进度显示 | 保存按钮显示"保存中 (2/5)" |
| 失败保留 | 部分失败时抽屉不关闭，方便修改重试 |

## 二、日历状态

统一使用半开区间 `[checkInDate, checkOutDate)`。入住日占用，退房日不占用。

| 状态 | 含义 | 数据来源 | 房客端是否可选 |
|------|------|---------|---------------|
| `AVAILABLE` | 可预订 | 默认或无占用 | 是 |
| `PENDING_CONFIRM` | 待房东确认 | `orders.status = PENDING` | 否 |
| `BOOKED` | 已确认占用 | 有效订单 | 否 |
| `CHECKED_IN` | 已入住 | 订单已入住 | 否 |
| `CHECKED_OUT` | 已退房 | 订单已退房 | 否 |
| `UNAVAILABLE` | 房东手动锁房 | availability 手动设置 | 否 |
| `LOCKED` | 临时锁定 | 订单并发锁或支付锁 | 否 |

状态优先级（格子展示时）：`CHECKED_IN > CHECKED_OUT > BOOKED > PENDING_CONFIRM > LOCKED > UNAVAILABLE > AVAILABLE`

## 四、后端接口

统一挂在 `/api/host/calendar` 下，权限 `@PreAuthorize("hasAnyRole('HOST', 'LANDLORD')")`。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/host/calendar` | 获取日历聚合数据（含订单、availability、价格） |
| GET | `/api/host/calendar/summary` | 获取顶部统计数据 |
| GET | `/api/host/calendar/export` | CSV 导出 |
| PATCH | `/api/host/calendar/availability` | 更新可用性（可订/不可订），含订单冲突检测 |
| PATCH | `/api/host/calendar/price` | 更新或清除自定义价格（`customPrice = null` 表示清除） |

### 4.1 核心 Service

`HostCalendarService` — 聚合日历数据：
1. `buildBaseDays`：为每套房源的每一天生成基础 AVAILABLE 记录
2. `applyAvailability`：叠加 `homestay_availability` 表数据（不可订、锁定、自定义价格）
3. `applyOrders`：叠加订单数据（BOOKED、PENDING_CONFIRM、CHECKED_IN、CHECKED_OUT）
4. `updateAvailability`：批量设置可订/不可订，冲突检测
5. `updatePrice`：设置或清除自定义价格

## 五、数据模型

### 5.1 数据库表

**`homestay_availability`**（按 `homestay_id + date` 唯一）

| 字段 | 类型 | 说明 |
|------|------|------|
| `homestay_id` | BIGINT | 房源 ID |
| `date` | DATE | 日期 |
| `status` | VARCHAR(20) | AVAILABLE / BOOKED / UNAVAILABLE |
| `source` | VARCHAR(30) | ORDER / MANUAL / SYSTEM |
| `reason` | VARCHAR(255) | 不可订原因 |
| `note` | TEXT | 房东备注 |
| `custom_price` | DECIMAL(10,2) | 房东自定义每日价格（V37 新增） |
| `created_by` | BIGINT | 操作人用户 ID |
| `locked` | BOOLEAN | 是否临时锁定 |
| `lock_expires_at` | DATETIME | 锁过期时间 |

### 5.2 DTO

## 六、实时同步

后端在可用性或价格变更成功后，通过 `SimpMessagingTemplate` 向 `/topic/calendar/{hostId}` 推送消息。前端 `websocketService.ts` 订阅该主题，收到后 dispatch `calendar-update` 事件，`useHostCalendar.ts` 监听到后自动 `loadCalendar()` 刷新数据。
