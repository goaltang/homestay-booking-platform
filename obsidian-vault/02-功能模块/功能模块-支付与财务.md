# 支付与财务模块

> [!info] 模块概述
> 支付与财务模块负责处理用户订单的支付流程、支付宝集成、房东收益结算等核心财务功能。是民宿预订交易闭环的关键环节。

## 涉及用户端

- **C 端用户** — 订单支付、支付状态查询
- **房东** — 收益明细查看、收益趋势分析、手动结算
- **管理后台** — 支付订单管理、退款处理（在订单管理中关联）

## 功能清单

### 1. 订单支付
- 选择支付方式（目前支持支付宝）
- 支付宝页面跳转支付
- 支付二维码（备用方案）
- 支付倒计时（2 小时内未支付自动取消订单）
- 模拟支付（开发测试环境）

### 2. 支付回调
- 支付宝异步通知接收
- 回调签名验证
- 订单状态更新（待支付 → 已支付）
- 支付结果通知前端

### 3. 收益管理（房东端）
- **收益明细** — 按时间范围、房源筛选，分页展示每笔收益
- **收益概要** — 总收益、总订单数、平均每单收益
- **收益趋势** — 按日/周/月统计收益变化趋势
- **月度收益** — 当月收益汇总
- **待结算收益** — 展示可结算但未结算的收益金额
- **手动结算** — 房东手动触发收益结算

## 支付流程

```
用户下单 → 订单确认页 → 选择支付宝支付
    ↓
POST /api/payment/{orderId}/create
    ↓
返回支付宝支付页面 URL → 浏览器跳转支付宝
    ↓
用户完成支付 → 支付宝异步通知
    ↓
POST /api/payment/alipay/notify
    ↓
验证签名 → 更新订单状态 → 创建收益记录
    ↓
前端轮询 /api/payment/{orderId}/status 确认支付结果
```

## 收益结算流程

```
订单完成入住退房 → 订单状态变为 COMPLETED
    ↓
系统自动生成收益记录（或房东手动触发结算）
    ↓
收益状态: PENDING（待结算）→ SETTLED（已结算）
    ↓
房东在收益管理页面查看明细和统计
```

## 后端 API

### 支付接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/payment/{orderId}/create` | 创建支付订单（传入支付方式） |
| GET | `/api/payment/{orderId}/status` | 查询支付状态 |
| POST | `/api/payment/{orderId}/mock-success` | 模拟支付成功（仅测试） |
| POST | `/api/payment/alipay/notify` | 支付宝异步回调 |

### 收益接口（房东端）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/host/earnings/detail` | 收益明细（支持时间、房源筛选） |
| GET | `/api/host/earnings/summary` | 收益概要统计 |
| GET | `/api/host/earnings/trend` | 收益趋势（日/周/月） |
| GET | `/api/host/earnings/monthly` | 当月收益 |
| GET | `/api/host/earnings/pending` | 待结算收益总额 |
| POST | `/api/host/earnings/settle` | 手动触发结算 |

## 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| `OrderPay.vue` | `/order/pay/:id` | 订单支付页（支付方式选择、倒计时、二维码） |
| `EarningManage.vue` | `/host/earnings` | 房东收益管理（明细、趋势、结算） |

## 数据结构

```typescript
// 收益记录
interface Earning {
  id: number
  hostId: number
  homestayId: number
  orderId: number
  amount: number        // 收益金额
  checkInDate: string
  checkOutDate: string
  nights: number
  status: 'PENDING' | 'SETTLED'
  isTest: boolean
  createdAt: string
}

// 支付状态
interface PaymentStatus {
  success: boolean
  isPaid: boolean
  paid: boolean
  message: string
}
```
