# 收藏与推荐模块

> [!info] 模块概述
> 本页保留“收藏”能力和推荐入口说明。推荐算法、用户画像、行为埋点和猜你喜欢等完整能力已拆分到 [[功能模块-个性化推荐]]；主动搜索能力拆分到 [[功能模块-房源搜索]]。

## 涉及用户端

- **C 端用户** — 收藏房源、取消收藏、查看我的收藏列表
- **系统** — 维护用户收藏关系，并把收藏行为作为推荐偏好信号

## 功能清单

### 1. 房源收藏
- **添加收藏** — 在房源详情页或列表页收藏房源
- **取消收藏** — 移除已收藏的房源
- **切换收藏** — 一键切换收藏状态（收藏/取消）
- **检查收藏状态** — 查看某个房源是否已收藏
- **批量检查** — 同时检查多个房源的收藏状态（用于列表页显示心形图标）
- **我的收藏列表** — 查看所有已收藏的房源详情
- **收藏 ID 列表** — 获取纯 ID 列表（用于快速比对）
- **清空收藏** — 一键清空所有收藏
- **收藏数量** — 获取收藏总数

### 2. 推荐入口
- **收藏信号** — 收藏房源会反映用户兴趣，可作为 [[功能模块-个性化推荐]] 的偏好来源
- **首页推荐入口** — 首页推荐、热门、猜你喜欢由 [[功能模块-个性化推荐]] 维护
- **详情页相似推荐** — 相似房源由 [[功能模块-个性化推荐]] 维护

## 后端 API

### 收藏接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/favorites/{homestayId}` | 添加收藏 |
| DELETE | `/api/favorites/{homestayId}` | 取消收藏 |
| POST | `/api/favorites/toggle/{homestayId}` | 切换收藏状态 |
| GET | `/api/favorites/check/{homestayId}` | 检查是否已收藏 |
| GET | `/api/favorites` | 获取我的收藏列表 |
| GET | `/api/favorites/ids` | 获取收藏 ID 列表 |
| DELETE | `/api/favorites/clear` | 清空收藏 |
| GET | `/api/favorites/count` | 收藏数量 |
| POST | `/api/favorites/check-batch` | 批量检查收藏状态 |

### 推荐接口

推荐接口统一归档到 [[功能模块-个性化推荐#后端 API]]。

| `Favorites.vue` | `/user/favorites` | 我的收藏列表 |

| `HomestayDetail.vue` | `/homestays/:id` | 房源详情页展示收藏按钮和相似推荐 |

## 收藏与推荐的关系

收藏本身是用户主动表达兴趣的强信号，推荐模块可以从收藏房源中提取：

| 偏好维度 | 来源 |
|---------|------|
| 城市偏好 | 收藏房源的城市编码 |
| 房型偏好 | 收藏房源的 `type` |
| 价格偏好 | 收藏房源价格区间 |
| 设施偏好 | 收藏房源的设施集合 |

收藏信号不直接等于推荐结果，但应参与 [[功能模块-个性化推荐]] 的用户画像和排序打分。
