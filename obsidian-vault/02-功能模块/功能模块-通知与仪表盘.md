# 通知与仪表盘

> Admin 端系统首页数据概览与通知入口。路由：`/dashboard`、`/notifications` | 权限：管理员

## 一、功能清单

### 1.1 系统首页（Dashboard）

| 功能 | 说明 |
|------|------|
| 查看关键指标 | 今日订单数、今日收入、待审核数、新用户数 |
| 查看快捷操作 | 常用功能入口快速跳转 |
| 查看最近活动 | 平台近期关键事件流 |
| 查看图表概览 | 订单/收入趋势图表 |

### 1.2 通知中心

Admin 端通知中心为管理员接收房源审核、系统公告等通知的入口。

| 功能 | 说明 |
|------|------|
| 查看通知列表 | 分页展示管理员收到的通知 |
| 筛选通知 | 按通知类型和已读状态筛选 |
| 标记已读 | 单条标记已读、全部标记已读 |
| 删除通知 | 删除单条通知 |
| 点击跳转 | 房源类通知跳转审核工作台/审核历史 |

> 通知中心完整架构见 [[功能模块-通知中心]]。

## 二、页面与组件

### 2.1 路由

| 路径 | 组件 | 说明 |
|------|------|------|
| `/dashboard` | `dashboard/index.vue` | 系统首页（Dashboard） |
| `/notifications` | `notifications/index.vue` | Admin 通知中心 |

### 2.2 Dashboard 组件结构

```
dashboard/index.vue
├── 指标卡片区域（今日订单/收入/待审核/新用户）
├── 快捷操作入口
├── 图表概览（订单趋势/收入趋势）
└── 最近活动流
```

### 2.3 通知中心组件结构

```
notifications/index.vue
├── page-header（标题 + 全部已读 + 刷新）
├── filter-section（类型筛选 + 状态筛选 + 搜索/重置）
└── notifications-list
    └── notification-item × N
        ├── 图标
        ├── 标题 + 时间 + 内容
        ├── entity meta（如房源ID tag）
        └── 标记已读 / 删除
    └── el-pagination
```

## 三、后端接口

### 3.1 Dashboard

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/dashboard/stats` | 获取 Dashboard 统计数据 |
| GET | `/api/admin/dashboard/activities` | 获取最近活动流 |

### 3.2 通知中心

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/notifications` | 获取通知列表（复用 C 端同一接口） |
| GET | `/api/notifications/unread-count` | 获取未读数量 |
| POST | `/api/notifications/{id}/read` | 标记已读 |
| POST | `/api/notifications/read-all` | 全部标记已读 |
| DELETE | `/api/notifications/{id}` | 删除通知 |

> 完整接口定义与 Service 层见 [[功能模块-通知中心]]。
