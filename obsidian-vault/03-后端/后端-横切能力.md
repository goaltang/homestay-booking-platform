# 后端横切能力（注解 + AOP）

> [!info] 概述
> 2026-08 集中落地的注解化横切能力：限流、操作日志、分布式锁、接口耗时统计、接口文档。统一模式：**自定义注解 + AOP 切面**，注解即用，无侵入业务代码。

## 1. 接口限流 @RateLimit

| 项 | 内容 |
|---|---|
| 注解 | `annotation/RateLimit.java` — `limit` / `windowSeconds` / `key`（默认 IP+类名.方法名） |
| 切面 | `aspect/RateLimitAspect.java` — Redis Lua 固定窗口（INCR + EXPIRE 原子操作） |
| 超限响应 | 抛 `RateLimitExceededException` → `GlobalExceptionHandler` 返回 **429** |
| 降级 | Redis 异常时放行（不因限流组件故障拖垮业务） |
| 使用点 | `PaymentController` 支付创建（30 次/分）、`AdminPromotionController` 批量发券（5 次/分，key=`admin:coupon-batch`）等 |

## 2. 操作日志 @OperationLog

| 项 | 内容 |
|---|---|
| 注解 | `annotation/OperationLog.java` — `operationType` / `resource` / `detail` / `resourceId` / `status` |
| 切面 | `aspect/OperationLogAspect.java` — 方法执行后异步落库 |
| SpEL | `detail` 与 `resourceId` 支持 SpEL 表达式，如 `"创建公告: #{#announcement.title}"`、`#{#id}` |
| 落库 | `entity/OperationLog.java` + `OperationLogService`（异步） |
| 覆盖 | 全仓库 69 处标注，管理端「系统 → 操作日志」可查 |

## 3. 分布式锁 @RedisLock

| 项 | 内容 |
|---|---|
| 注解 | `annotation/RedisLock.java` — `key`（SpEL）/ `timeoutSeconds` |
| 切面 | `aspect/RedisLockAspect.java` — try/finally 释放，SpEL 解析失败不影响业务 |
| 底层 | `util/RedisLock.java` — RedisTemplate + Lua 原子解锁，Redis 不可用降级无锁 |
| 使用点 | 支付回调（`payment:notify:#{#result.outTradeNo}`）、通知清理（`NotificationCleanupService`） |

## 4. 接口耗时统计 ApiTimingAspect

- `aspect/ApiTimingAspect.java` — 统计 REST 接口执行耗时
- 用于定位性能瓶颈，配合压测报告使用

## 5. 接口文档 springdoc

| 项 | 内容 |
|---|---|
| 依赖 | `org.springdoc:springdoc-openapi-starter-webmvc-ui:2.2.0` |
| 配置 | `config/OpenApiConfig.java`（title「民宿预订系统 API」、bearerAuth 安全方案） |
| 访问 | 启动后 `/swagger-ui.html`（UI）、`/v3/api-docs`（OpenAPI JSON） |

## 6. 其他 2026-08 工程化能力

- **LLM 调用重试**：`service/agent/LlmClient.java` `@Retryable`（3 次、退避 1s×2），应用类 `@EnableRetry`
- **首页统计并行化**：`service/HomeService.java` 五路 `CompletableFuture` 并行 count + `allOf().join()`（压测对比见 [[性能压测报告-首页统计并行化对比]]）
- **仪表盘真实环比**：`AdminStatisticsController` 统计接口补充昨日数据，前端计算真实环比
