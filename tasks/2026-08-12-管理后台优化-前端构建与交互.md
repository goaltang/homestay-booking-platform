## 任务 A：构建体积优化（消除 Element Plus 全量引入）

现状：src/main.ts 里 `import ElementPlus from "element-plus"` + `app.use(ElementPlus)` 全量注册组件，与 vite.config.ts 已有的按需配置（AutoImport + Components 的 ElementPlusResolver）冲突，全量 use 把整个库打进主 chunk。

要求：
1. main.ts 移除 `app.use(ElementPlus)`（组件已按需自动导入）。**保留** `import "element-plus/dist/index.css"` 全局样式行，避免指令/样式回归。
2. **保留**图标全量注册循环（main.ts 的 `for (const [key, component] of Object.entries(ElementPlusIconsVue))`）——侧边菜单用字符串图标 `<component :is="item.icon">`，删了菜单图标全挂。不要改 src/config/menu.ts 的数据结构。
3. vite.config.ts 的 build.rollupOptions.output.manualChunks 手动分包，建议：
   - element-plus 相关（element-plus 及依赖）
   - echarts + zrender
   - element-china-area-data
   - vue/vue-router/pinia 等核心
4. 验证：npm run build 必须 0 错误；对比 main index chunk 是否明显缩小（目标：gzip 从 357KB 降到 200KB 以下）；build 后用 dev server 打开页面（登录后进仪表盘），检查浏览器控制台无 v-loading 指令失效等报错——如果 v-loading 失效，说明 ElementPlusResolver 需要 directives 支持，在 vite.config.ts 里处理（如 resolver 传 { directives: true } 或按需导入 ElLoading 指令），不要绕开问题。

约束：不 npm install 任何新依赖；不动 style.css 的 :root 主色变量。

## 任务 B：路由切换顶部进度条（零依赖）

现状：views/layout/index.vue 的 router-view 包了 transition fade（0.3s），路由懒加载的大页面（审核工作台 2400 行等）首次进入要 1-3 秒编译，期间无任何视觉反馈，用户感觉"点击没反应"。

要求（不用 nprogress，自写轻量实现）：
1. 在 layout 顶部（header 上方或 el-main 顶部）加一条 2px 高的进度条元素，颜色用 `var(--el-color-primary)`，默认隐藏（宽度 0 / opacity 0）
2. 路由开始切换时显示并推进（可用 CSS transition 模拟：显示后宽度快速到 ~80%），切换完成（afterEach）后补满 100% 再淡出
3. 在 layout 组件内监听 router 事件，或改 router/index.ts 的守卫（**不要改鉴权逻辑**，只加进度条控制）
4. 注意首次进入大页面编译期间进度条要保持在可见状态

## 任务 D：分页逻辑抽 composable

现状：src/views/system/LoginLog.vue 与 OperationLog.vue 各有一份重复分页逻辑：query 里 pageIndex/pageSize、handleSearch/clearSearch/handlePageChange/handleSizeChange、getLogs 里 `page: query.pageIndex - 1`（后端 0-based）。

要求：
1. 新建 src/composables/usePagination.ts，封装：pageIndex/pageSize 状态、currentChange/sizeChange/reset（重置页码为 1）、构建 API 参数的方法（返回 { page: pageIndex-1, size }）
2. LoginLog.vue、OperationLog.vue 改用 composable，删除各自重复的页码处理函数
3. 两个页面的查询参数结构必须保持不变（后端契约不变）：page/size/筛选字段/dateRange
4. 注意：这两个文件今天刚补过 query 类型注解（`LogQueryParams & { pageIndex: number; pageSize: number; dateRange?: string[] }`），改造时保持类型正确，vue-tsc 必须 0 错误
