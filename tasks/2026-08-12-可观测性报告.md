## 三、排障记录（本次修复的 4 个问题）

1. **`MetricsConfig` 启动失败**：`@Configuration` + private 构造器 → Spring CGLIB 代理报 "No visible constructors"。该类只有静态方法、无需是 Bean，**去掉 `@Configuration` 注解**（保持 private 构造器的工具类形态），修复让系统更简单。
2. **限流埋点破坏降级路径**：原实现把 `methodLabel(joinPoint)` 放在 try 内，若 signature 为 null 会 NPE 并被"降级放行" catch 吞掉 → 超限静默放行（`RateLimitAspectTest.超限时抛RateLimitExceededException` 因此失败）。**修复：method 标签在 try 外一次性计算**，try 内异常路径与埋点前完全一致（埋点只加不改）；测试同步 stub signature。
3. **`/actuator/prometheus` 404**：Spring Boot 3 的 `@SpringBootTest` 默认经 `DisableObservabilityContextCustomizer` 关闭指标导出（`management.metrics.export.prometheus.enabled=false`），prometheus 端点根本不注册。**修复：测试类加 `@AutoConfigureObservability`**。（/actuator/metrics 200、/actuator/prometheus 404 的差异即此）
4. **`ApplicationIntegrationTest` health 503**：actuator 加入后 health 端点存在，测试环境 ES 未起 → 健康检查 DOWN → 503。503 是健康端点对依赖 DOWN 的合法响应，测试断言集合补上 `SERVICE_UNAVAILABLE`。

另：首次 `mvn -o test-compile` 报 `micrometer-registry-prometheus:1.10.3 (present, but unavailable)`——jar 已在本仓库但 `_remote.repositories` 记录的远程仓库 id 与当前 settings（alimaven 镜像）不一致。用一次**在线** `mvn test-compile`（网络可用）让 Maven 以当前 id 重新校验记录后，`mvn -o` 全部命令正常。全程未读写被禁止的 maven 仓库目录 / ~/.m2。

## 四、Prometheus 抓取配置说明

- 后端以 `mvn spring-boot:run` 跑在宿主机 8081（WSL），指标端点 `/actuator/prometheus`（Security 已 permitAll）。
- Docker 容器内 Prometheus 通过 **`host.docker.internal:8081`** 访问宿主机后端（WSL2/Docker Desktop 场景的标准方式），15s 抓一次，job 名 `homestay-backend`，标签 `app=homestay-backend`。
- Grafana（localhost:3000，admin/admin123）启动即通过 provisioning 自动注册 Prometheus 数据源（uid=`prometheus`）并自动加载 `grafana-dashboard.json`，无需手动配置/导入。
- 指标速览（Prometheus 格式下点转下划线）：
  - `homestay_ratelimit_blocked_total{method=...}` 限流触发
  - `homestay_mq_consumed_total{scenario=order.timeout|coupon.batch|notification.push}` MQ 成功消费
  - `homestay_mq_retried_total{scenario=...}` MQ 重试
  - `homestay_order_timeout_cancelled_total` 订单超时自动取消
  - `homestay_llm_requests_total{result=success|failure}` LLM 调用成败
  - `homestay_home_stats_duration_seconds{_sum,_count,max,bucket}` 首页统计耗时
  - 内置：`jvm_memory_used_bytes`、`http_server_requests_seconds_count` 等
