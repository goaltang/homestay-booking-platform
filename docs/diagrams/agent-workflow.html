阅读说明与范围

模型决策返回 JSON；工具执行结果进入下一轮决策，最多调用 properties.maxToolHops 次，之后基于工具轨迹生成回答。无工具数据时提示词要求不确定信息转人工；不是引入向量库的 RAG 流程。

7 个只读工具包括订单查询、退款预览、入住/退房信息、房源详情、评价统计与计价；3 个写工具只起草 request_user_refund、cancel_order_with_reason、raise_dispute_by_guest。

回答轮返回 answer 和可能的 pendingAction；前端确认卡片让房客确认或取消。确认接口要求 action / orderId / reason，并重新 requireGuestOrder 校验，再执行对应业务动作。取消订单确认为真正取消，退款确认为提交申请。

敏感问题、超过会话轮数或外部调用异常会兜底转人工；工具越权失败会转成错误文本交给回答轮。图中折叠了多次模型调用与这些异常分支。

管理员争议辅助是另一入口：汇总时间线、聊天和相似案例生成建议草稿；不会自动调用 resolveDispute，未画成客服确认接口的一部分。
