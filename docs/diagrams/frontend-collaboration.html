阅读说明与范围

图示范围是 homestay-front：同一个 C 端包含房客与房东页面。管理端独立应用未在本图展开；路由守卫是界面访问控制，最终权限由后端执行。

页面既可直接调用领域 API，也可调用 Pinia action；Pinia 包含 user、search、booking、order、chat、notification 等。图中不是每个请求都必须先经过 Store。

api/index.ts 导出 utils/request.ts 的 Axios 实例；共享请求设置 withCredentials、超时、FormData 头处理和响应错误提示。当前请求拦截器未主动附加 Bearer token，不能依据旧注释画成自动加 token。

WebSocket 的通知与聊天订阅分别调用 notificationStore 和 chatStore；日历事件另有处理。图中折叠连接、重连和各事件分发，不把所有消息都画成同一种后端业务。

响应式状态变化驱动页面更新；HTTP 成功与实时事件可能由不同路径到达。图中不宣称统一去重、离线补发或实时事件必达。

代码核对入口：index.ts · index.ts · request.ts · chat.ts · notification.ts · websocketService.ts
