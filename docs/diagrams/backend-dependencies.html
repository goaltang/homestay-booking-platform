阅读说明与范围

图中箭头由调用/注入方指向依赖方；只展示订单子系统中选定的直接服务依赖。fan-in 角标只统计本图，不能当作全仓库调用次数。

OrderService 委托 OrderLifecycleService，另依赖 PricingService 和 PaymentProcessingService；生命周期依赖计价、预订冲突和优惠券，计价与支付处理也依赖优惠券，因此本图有多父共享依赖，不是树。

Repository、DTO 装配、通知、系统配置、营销、收益及其他依赖按范围省略；PaymentProcessingService 到 EarningService 是选取的一条收益依赖，其余收益调用不在图中统计。

这些服务位于同一个 Spring Boot 应用，不是多个独立部署的微服务。图中没有添加未经确认的循环依赖，也不据选定子图宣称全仓库无环。

代码核对入口：OrderServiceImpl.java · OrderLifecycleServiceImpl.java · PricingServiceImpl.java · PaymentProcessingServiceImpl.java
