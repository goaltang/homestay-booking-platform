MySQL、Redis、Elasticsearch、RabbitMQ 与后端位于同一个 Compose 默认网络；容器内部使用服务名连接，不使用宿主机映射端口访问彼此。

MySQL、Redis、ES 配有命名卷；RabbitMQ 当前未配置存储卷。ES 使用本地镜像 homestay-es-ik:test，标签不能证明具体 ES / IK 版本。

图上端口同时存在宿主机映射：3306、6379、9200、5672，RabbitMQ 管理台为 15672。用户名、密码和密钥不列入图中。

Compose 还包含 Prometheus 9090 和 Grafana 3000，本图为控制阅读密度未展开。当前没有运行验证，不宣称高可用、备份或公网隔离已实现。
