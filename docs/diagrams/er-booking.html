阅读说明与范围

同一个 User 实体承载房客和房东：房源的 owner 与订单的 guest 是两条不同关系。每个房源/订单必须关联一个相应用户。

一个订单可有多次支付尝试，所以 PaymentRecord 为 0..N；OrderPriceSnapshot.orderId 唯一，因此订单对应 0..1 个快照。新下单成功路径要求保存快照，但模型图兼容历史或未完整创建记录。

Review.order 为可空且唯一的 @OneToOne，所以订单对应 0..1 条评价；评价还直接关联 User 与 Homestay，为避免重复连线未展开这两条关系。

PaymentRecord.orderId 与 OrderPriceSnapshot.orderId 是普通 ID 字段，图中表示逻辑关系，不宣称它们都是 JPA 关联或数据库外键。入住退房、收益和争议记录在本图省略。
