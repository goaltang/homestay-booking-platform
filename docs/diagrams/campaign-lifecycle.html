阅读说明与范围

房东创建活动为 DRAFT；每分钟自动启用开始时间已到且未过期的 DRAFT，并结束超期 ACTIVE。管理员可手动启用或暂停，房东可暂停/结束自己的活动；端点直接设状态，图中不是严格完备状态机。PAUSED 不参与自动结束查询。

匹配要求 ACTIVE 且在时间窗口内，按活动 priority DESC 读取；每活动选适用规则中优惠最大的规则，受剩余预算限制。若有匹配的非叠加活动，只返回其中优惠最大者，否则返回叠加活动。这里与动态定价规则 priority ASC 不同。

下单事务中条件 UPDATE 扣减 budgetUsed，余额不足导致下单回滚，并写 PromotionUsage=LOCKED。达到 80% 仅置预算预警标志；预算耗尽将活动设 ENDED，不宣称发送了告警消息。

支付成功后尝试将订单使用流水改 USED。取消路径将流水标 RELEASED / REFUNDED 并调用预算回退；异常会被捕获记录，回退方法的 false 结果在该调用点未见处理，不宣称必然补偿成功。

预算回退只减少 budgetUsed，不自动将 ENDED 恢复 ACTIVE。活动状态和订单流水是两套状态，图中分开呈现；没有添加未实现的统一强一致补偿流程。
