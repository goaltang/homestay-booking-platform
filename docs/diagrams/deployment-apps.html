阅读说明与范围

当前 Compose 包含完整应用栈。浏览器访问宿主机 8088 / 8089，分别映射到 C 端和管理端 Nginx 的 80；两个 Nginx 的 /api/、/uploads/、/ws 代理到 backend:8081。

后端容器运行 prod profile，宿主机也暴露 8081；uploads 绑定挂载到 /app/uploads。该图没有额外负载均衡器、多副本或 TLS 终止，因为当前文件没有配置这些组件。

本地开发另有 Vite 5173 / 5174，API 8081；这些开发端口不是本图的前端容器入口。所有容器使用 Compose 默认网络，未指定专用网络名称。

当前 WSL 无可用 Docker 命令，未启动或联调容器。完整启动需要 .env 与本地 ES IK 镜像；监控服务和外部支付/LLM 调用在此图省略。
