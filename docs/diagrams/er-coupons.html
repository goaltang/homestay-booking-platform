阅读说明与范围

CouponTemplate → UserCoupon 是 @ManyToOne 的反向关系；UserCoupon.userId、lockedOrderId、usedOrderId 为普通 Long 字段，连线表示逻辑归属，不宣称数据库外键。

每张用户券属于一个用户与一个模板；一个用户/模板可以有 0..N 张券。一个订单可以锁定或使用多张券；一张券的每种订单引用最多一个，未绑定时为 0。

下单锁券 LOCKED，支付成功核销 USED，取消等路径释放券；两个订单 ID 字段表达不同生命周期含义，不是两张独立关联表。

模板额度、领取限制、规则快照、活动与营销流水未展开；订单的争议/退款不会简单等价于自动返还每一张已使用券。

代码核对入口：User.java · CouponTemplate.java · UserCoupon.java · Order.java · CouponServiceImpl.java
