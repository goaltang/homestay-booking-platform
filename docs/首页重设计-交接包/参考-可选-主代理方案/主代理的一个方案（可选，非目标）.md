## 3. 目标设计（对齐既有 token，不新造配色）

### 3.1 设计决策（已定，不要再问）

1. **配色只用现有 token**：主色 `--color-primary-500:#d45f2e`（陶土）承担全部主 CTA；辅色 `--color-secondary-500:#558555`（鼠尾草）只给「地图找房」「信任/保障」这类次入口；底色 `--color-neutral-50:#faf9f7`；边框 `--color-neutral-200:#e6e2db`；正文 `--color-neutral-900:#1f1c19`；次要文字 `--color-neutral-500:#8a8276`。
2. **容器统一 1200px**（`--container-max`）：删掉 `Home.vue:417` 的 1280，`AnnouncementBar.vue:62` 一并对齐。
3. **断点只用 token 档位**：640（大手机）/ 768（平板竖）/ 1024（小桌面）/ 1280（标准桌面）。**新增响应式样式只允许用这 4 个值**，不要再引入 900/992/576/480。
4. **Hero 用实景图**（`Banner.imageUrl` 已有字段），不再用 `bgGradient` 色块；返回 `imageUrl` 为空时回退到 `--color-background-warm` + 现有文案，不做渐变。
5. **圆角不统一放大**：卡片/面板 12–16px，chip 与按钮才用 pill（`MASTER.md:30-39` 明确禁止「统一 16px+ 大圆角」）。
6. **不加 Emoji 功能图标**（规范禁止）；沿用 Element Plus 图标或现有 `CustomIcons.vue`。
7. **深色模式本次不做**：删掉 `SearchBar.vue:849-852` 的空 `@media (prefers-color-scheme: dark)` 占位，并在 `MASTER.md` 里把「支持明暗模式」改成「待实现」，避免规范与实现继续打架。

### 3.3 关键组件规格

**Hero + 搜索**

- 结构：全出血图（`object-fit:cover`）+ 单侧左→右暗罩 `linear-gradient(90deg, rgba(31,28,25,.80), rgba(31,28,25,.12))`；文案左对齐，`--text-hero`；kicker（如「贵州 · 42 个目的地已上线」）+ 标题 + 一行副文案 + 主 CTA（陶土）+ 次 CTA（描边）。
- 搜索条：桌面单行 4 段（目的地 / 入住·退房 / 房客 / 圆形主色按钮），`border-radius:16px`，`--shadow-md`，**只保留一套宽度真值 1200px**（删 `SearchBar.vue:486` 的 900 与 `Home.vue:403` 的 920）。
- 手机：`min-height:56px` 的一行摘要条（`你要去哪里？ / 添加日期 · 1 位房客` + 圆形按钮），点击后打开底部抽屉式搜索面板（`el-drawer` 或现有 `SearchBar` 的移动端面板），**不要在首屏堆 5 个字段**。
- 触屏可见性：轮播必须显示指示点（现在 `indicator-position="none"` + `arrow="hover"`，触屏什么都看不到）。

**房源卡片**

- 图 4:3（`aspect-ratio`），圆角 12px，右上心形收藏按钮 36×36（触摸目标≥44 时用 padding 补足）。
- 正文只留：标题（最多 2 行，`-webkit-line-clamp:2`，**删掉 `white-space:nowrap`**）→ 一行 meta（城市·区 ｜ ★评分 ｜ N 条）→ 价格 `--text-price` + `/晚`。
- 去掉：`distanceFromCenter` 行、`groupName` 徽标（保留数据、默认不渲染）、feature 标签行（最多 1 个「即时预订」徽标）。
- 加载骨架列数必须与真卡一致（同一套 `grid-template-columns`，抽出共享 class 或 CSS 变量，别让 `HomestaySection` 4 列包 `HomestaySkeleton` 3 列）。

**移动端（≤640）**

- 卡片横排小卡：图 112px 固定宽，正文 `title 15px/2 行` + meta `12px 单行省略` + 价格。
- 底部固定 tab 栏（找民宿/收藏/订单/我的），高 56px，正文 `padding-bottom:60px` 让位（原 `BookingCard` 的「不做底部固定栏」决策只针对详情页，首页可以加）。
- 页面禁止横向滚动：所有宽度用 `%`/`minmax(0,1fr)`/`min-width:0`，不要用固定 px 撑开容器。
